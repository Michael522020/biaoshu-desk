# 标枢

在浏览器里写技术标。资料、要求、章节、报价和审核记录保存在本机 IndexedDB，不上传到应用服务器。

## 能做什么

- 导入 txt、Markdown、Word、Excel、PDF，并从语句里整理招标要求
- 把要求分到章节，手改响应状态
- 生成本地提纲；配置兼容接口后，也可以让模型按当前章节和资料摘录起草
- 没有依据的承诺会保留为「待人工补充」
- 交付分：要求响应 40%、证据完备 25%、章节完成 25%、人工放行 10%
- 报价清单按数量、单价、税率计算税额
- 在当前项目里检索要求、章节和资料
- 审核稿可以随时导出 Word；正式稿要等核心要求、证据、正文和人工放行都完成
- 矩阵、评分和报价可以导出到同一个 Excel

## 运行

```bash
npm install
npm test
npm run dev
```

打开 http://localhost:5173/ 。首页可以「打开示例」，看桥梁巡检这组虚构数据。

模型在「模型」页配置。选本机 Ollama 时，地址会填成 `http://127.0.0.1:11434/v1`，密钥可以留空。密钥只放在当前浏览器会话里。
